# NexusOps AI

NexusOps AI is an intelligent business workflow automation platform that helps organizations create, classify, and track operational requests.

## Features

- Create business requests
- Automatic department classification
- Priority management
- Request status tracking
- React-based dashboard
- FastAPI REST API
- Frontend and backend integration
- CORS-enabled API communication

## Technology Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Python
- FastAPI
- Uvicorn
- Pydantic
